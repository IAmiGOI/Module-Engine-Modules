# Сторонние Модули — по одной ссылке на GitHub в строке. Они НЕ проверены каталогом: движок покажет это в предпросмотре.
# Допустимые формы:
#   owner/repo                                          -> index.js в корне репозитория
#   https://github.com/owner/repo                       -> то же
#   https://github.com/owner/repo/tree/<ref>/<папка>    -> <папка>/index.js
#   https://github.com/owner/repo/blob/<ref>/<файл>.js  -> именно этот файл
# Пустые строки и всё после «#» игнорируется.
